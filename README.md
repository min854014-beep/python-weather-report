# ☀️ 날씨 예보 프로그램 (Open-Meteo API)

창의공학설계 4주차 실습 과제: Git / GitHub / Git Graph를 활용한 버전 관리 및 날씨 예보 프로그램 개발

## 📌 과제 개요
- Open-Meteo 날씨 API(무료, 인증키 불필요)를 활용하여 사용자가 입력한 지역의 3일간(오늘, 내일, 모레) 날씨 예보를 조회합니다.
- 매일 오전 6시와 오후 3시 기준으로 날씨 상태(맑음, 주로 맑음, 흐림 등), 기온, 강수확률, 습도, 풍속 및 일일 최저/최고 기온을 출력합니다.
- 조회된 날씨 정보를 JSON 파일(`weather_{지역}_{일시}.json`)로 저장할 수 있습니다.
- Git 브랜치 6개를 생성하고 병합(Merge)하여 체계적인 버전 관리를 수행했습니다.

## 🚀 주요 기능
1. **지역 입력 및 좌표 변환**: 한국 주요 도시(서울, 천안 등) 사전 좌표 및 Open-Meteo 지오코딩 API 지원
2. **3일간 예보 제공**: 오늘, 내일, 모레 오전 06:00 / 오후 15:00 날씨 상태 및 상세 수치 제공
3. **날씨 상태 아이콘 및 한글 매핑**: WMO 날씨 코드를 한글 텍스트 및 이모지로 변환
4. **JSON 데이터 저장**: 필요 시 날씨 조회 결과를 타임스탬프 기반 JSON 파일로 저장
5. **Git 버전 관리**: 최소 5개 이상의 기능 브랜치를 활용하여 점진적으로 기능 구현 및 병합(Merge)
